# AdlinMart 🛒

AdlinMart adalah website toko kelontong modern yang dibuat sebagai project pembelajaran untuk menerapkan HTML, Bootstrap, dan SASS.

## ✨ Fitur

- 🏠 Hero Section dengan carousel
- 🛍️ Daftar produk
- 🎉 Informasi promo
- 🖼️ Galeri produk
- 💬 Testimoni pelanggan
- ❓ FAQ
- 📍 Lokasi toko menggunakan Google Maps
- 📩 Form kontak
- 📱 Responsive untuk desktop, tablet, dan mobile

## 🛠️ Teknologi

- HTML5
- Bootstrap 5
- SASS / SCSS
- JavaScript
- CSS3

## 🎯 Tujuan Project

Project ini dibuat untuk mempraktikkan penggunaan Bootstrap dan SASS dalam membangun website yang responsif, terstruktur, dan memiliki tampilan modern.
